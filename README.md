# デジタル化ラボ

中学校「情報の技術」の授業で使う、情報のデジタル化を体験するウェブアプリです。Chromebookのブラウザでそのまま使えます。

- `index.html` … トップページ
- `digital-lab-1.html` … 情報のデジタル化(1)：アナログとデジタル、0と1とビット、情報の量の単位、音のデジタル化（A/D変換）、文字のデジタル化（文字コード）

マイク録音を使うには、GitHub Pagesなど https のページで開いてください。
- `bit-runner.html` … ボーナスゲーム「デジタル進化ラン」：ステージが進むと2色→4色→16色→256色→フルカラーに進化し、難しくなる横スクロールゲーム
